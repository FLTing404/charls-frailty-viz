## —— 浙江大学《可视化导论》课程大作业设计报告

## 1. 项目背景与分析任务定义

### 1.1 背景：中国人口老龄化与衰弱问题

截至 2025 年，中国 60 岁以上人口已超过 3 亿，占总人口比例突破 21%，正式步入"中度老龄化"社会。在老龄化研究中，**衰弱（Frailty）** 被视为比"年龄"更能预测老年人不良预后的核心指标。衰弱指个体因生理储备下降而对外界应激源易感性增加的临床状态，与跌倒、住院、失能甚至死亡高度相关。

CHARLS（中国健康与养老追踪调查）是由北京大学国家发展研究院主持的全国性大型追踪调查项目，覆盖 150 个县、450 个社区，自 2011 年起每 2–3 年追踪一次。本项目基于 CHARLS 2011–2018 年四波调查数据，构建可视分析系统，探索中国中老年人衰弱的空间分布、身体功能损伤模式及其时间演变。

### 1.2 为什么用可视化而非纯统计/机器学习方法？

| 方法 | 局限性 |
|------|--------|
| 传统回归/Logistic 模型 | 仅能给出"某因素显著"的统计结论，无法展示个体层面轨迹异质性、亚群体结构性差异 |
| 机器学习（随机森林/XGBoost） | 预测精度虽高，但"黑箱"难以揭示因素协同/拮抗，不支持政策制定者的交互式子群体探索 |
| 结构方程模型（SEM） | 因果路径假设刚性，难以适应"多因一果、因因相关"的复杂性 |

**可视化不可替代的价值：** 通过**信息图式（Infographic）叙事布局**与**多视图协调**，分析师可同时完成宏观空间扫描（地图）、中观身体功能画像（人体隐喻图）、微观分布比较（箱线图/小倍数图）与纵向轨迹追踪（桑基图/面积图），形成"空间—身体—时间"三维穿透式分析。

### 1.3 分析任务定义

| 任务 ID | 分析任务 | 操作类型 | 主要承载页面 |
|---------|---------|---------|-------------|
| **T1** | 探索某一年全国/分省衰弱与慢病负担的空间格局 | 空间/总览 | Page A（单年快照） |
| **T2** | 理解衰弱相关慢病、ADL/IADL 失能在身体上的分布与并发症风险 | 比较/关系 | Page A（人体隐喻图） |
| **T3** | 比较不同区域/城乡/性别群体的 FI 分布差异 | 分布/比较 | Page A + Page B（箱线图） |
| **T4** | 追踪 2011–2018 衰弱状态转移与 FI 总体趋势 | 时序/关系 | Page B（多年趋势） |
| **T5** | 识别多维因素（SES、睡眠、社交、ACE）与衰弱的关联结构 | 相关/探索 | Page B（热力图 + 平行坐标） |
| **T6** | 通过 Brushing & Linking 发现高危亚群体并下钻个体 | 探索/细节 | 双页共享 + Details-on-Demand |

### 1.4 设计灵感与参考边界

本系统视觉叙事借鉴了公共卫生领域**信息图式 Dashboard**（参考：糖尿病全球负担信息图设计范式），其核心特征为：

- **中心地图 + 侧边人体隐喻**：地图承担"Where"，人体承担"What hurts"
- **小倍数（Small Multiples）**：分区域/分年份的重复编码，支持视觉比较
- **高级统计图**：箱线图展示分布而非仅均值，面积图强调趋势累积感
- **象形图（Isotype / Unit Chart）**：用图标矩阵降低数字认知负荷

> **声明：** 上述为**设计思想借鉴**；数据、分析任务、视图组合与交互逻辑均为本团队针对 CHARLS 衰弱数据的**原创适配**，非简单换皮。

## 2. 数据说明

### 2.1 数据来源

- **数据集：** CHARLS（China Health and Retirement Longitudinal Study）
- **来源机构：** 北京大学国家发展研究院
- **数据许可：** 学术研究免费开放，需在 charls.pku.edu.cn 注册申请
- **调查波次：** 2011（Wave 1）、2013（Wave 2）、2015（Wave 3）、2018（Wave 4）

### 2.2 数据规模与结构

**核心数据集：衰弱指数（Frailty Index, FI）**

| 年份 | 样本量 | 变量数 | 主要字段 |
|------|--------|--------|---------|
| 2011 | 43,182 | 36 | 10 种慢病、ADL/IADL、认知、cognition、FI、frailty_cat |
| 2013 | 25,586 | 36 | 同上（追踪子队列） |
| 2015 | 25,586 | 36 | 同上 |
| 2018 | 25,586 | 36 | 同上 |

> **纵向追踪：** 25,586 人在 2013–2018 四波 ID 完全一致，支持状态转移分析；2011 另有 17,596 人为基线扩展样本。

**关联数据集（按 ID join）：**

| 数据集 | 样本量/波 | 关键维度 |
|--------|----------|---------|
| SES | 17,708/波 | 教育、家庭消费、就业、户籍 |
| 睡眠/抑郁 | 17,370/波 | CESD-10、睡眠时长、性别、城乡 |
| 社会参与 | 17,708/波 | SC_Structural / Support / Engagement / Total |
| 医疗保健 | 17,708/波 | 医保、自付费用、就医满意度 |
| ACE | 20,654 | 24 项童年逆境 |
| 物质环境 | ~12,000/波 | 住房设施、region（East/Central/West） |

### 2.3 地理编码说明

CHARLS 样本 `ID` 前 3 位为**县级 PSU 编码**，可映射至：
- **省级聚合：** 用于 Choropleth 地图（31 省自治区直辖市）
- **东中西部：** `material_circumstances` 中 `region` 字段（East / Central / West）
- **城乡：** `sleep` / `ses` 中 `rural` / `hukou` 字段

预处理阶段将计算 `province_code`、`region`、`mean_FI_by_province` 等聚合字段，供地图与气泡图使用。

### 2.4 数据统计摘要

**衰弱分类分布（2011–2018）：**

| 年份 | 健壮 | 衰弱前期 | 衰弱 | 缺失 |
|------|------|---------|------|------|
| 2011 | 58.2% | 11.4% | 11.8% | 18.6% |
| 2013 | 38.4% | 22.2% | 11.7% | 27.7% |
| 2015 | 42.7% | 24.7% | 14.6% | 18.0% |
| 2018 | 36.0% | 25.2% | **16.3%** | 22.6% |

**FI 分布（2011）：** 均值 0.105，中位数 0.011，标准差 0.180，呈严重右偏——多数个体低衰弱，尾部极高风险人群需重点可视化。

## 3. 系统总体架构：双页面 + 合成展示大图

### 3.1 三层交付形态

本系统采用**"交互探索 + 静态叙事"**双轨交付，对应课程对 Demo 视频、答辩海报与可运行系统的不同需求：

```
┌─────────────────────────────────────────────────────────────┐
│  Layer 3 · 合成展示大图 Poster（3840 × 4320 或 A0 竖版）      │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Page B 静态截图 · 多年趋势区（上）                    │   │
│  ├─────────────────────────────────────────────────────┤   │
│  │  Page A 静态截图 · 单年快照区（下）                    │   │
│  └─────────────────────────────────────────────────────┘   │
│  用于：答辩投影 / Demo 视频封面 / 中期海报                    │
├─────────────────────────────────────────────────────────────┤
│  Layer 2 · Page B  `/trends`   多年趋势分析页（交互）         │
├─────────────────────────────────────────────────────────────┤
│  Layer 1 · Page A  `/snapshot` 单年健康快照页（交互）         │
└─────────────────────────────────────────────────────────────┘
```

| 交付物 | 路径/形式 | 用途 |
|--------|----------|------|
| **Page A** | `/snapshot?year=2018` | 答辩现场操作：选一年，看空间+身体+分布 |
| **Page B** | `/trends` | 答辩现场操作：看 2011→2018 演变与轨迹 |
| **Poster** | `poster.html` 或导出 PNG | 3–5 分钟 Demo 视频的"一图读懂"终帧 |

**合成大图生成方式：**
1. 两页分别调至"展示模式"（隐藏筛选控件，固定高对比配色）
2. 使用 `html2canvas` / Puppeteer 全页截图（推荐宽度 1920px）
3. 在 Figma 或 CSS `flex-direction: column` 中上下拼接，加统一标题栏与图例
4. 输出 `AgeVital_Poster_Full.png`（建议 3840×4800，300 DPI）

### 3.2 视觉设计规范（Infographic 风格）

参考糖尿病信息图的设计语言，建立 AgeVital 专属视觉系统：

| 元素 | 规范 | 课程理论依据 |
|------|------|-------------|
| **主色板** | 青绿渐变 `#0D9488 → #5EEAD4` + 米白背景 `#F8FAFC` | 医疗/健康语义；降低视觉疲劳（Ware, 2012） |
| **衰弱语义色** | Robust `#10B981` / Pre-Frail `#F59E0B` / Frail `#EF4444` | 有序分类的自然映射（Mackinlay, 1986） |
| **标题层级** | H1 72px 全大写 / H2 模块名 28px / 数据大字 48–96px | 格式塔接近性：数字与标签分组 |
| **图标体系** | 统一线性 icon（器官、医保、社交） | 降低认知负荷（Pictorial Superiority） |
| **网格** | 12 列 CSS Grid，模块间 24px gutter | 信息图式对齐与韵律感 |

**布局草图（借鉴参考图中心地图 + 右侧人体结构）：**

#### A1 · 中国 Choropleth 地图 + 比例符号气泡图

| 属性 | 说明 |
|------|------|
| **图表类型** | 分省 Choropleth（填色）+ Proportional Symbol（气泡面积=样本量） |
| **视觉通道** | 饱和度编码省均 FI；气泡面积编码 n；描边高亮选中省 |
| **数据** | `communityID`/`PSU` 聚合至省级 `mean_FI`, `frail_rate`, `n` |
| **理论** | 地理可视化（MacEachren, 1995）；面积通道精度低于位置，故 FI 用颜色、样本量用面积，避免双重面积误导（Cleveland & McGill, 1984） |
| **交互** | 点击省份 → 触发 `provinceSelected` 事件 → 人体图/箱线图/象形图同步过滤 |

#### A2 · 人体功能隐喻图（Body Metaphor Visualization）

| 属性 | 说明 |
|------|------|
| **图表类型** | **隐喻图（Metaphoric Visualization）**—— SVG 人体轮廓 + 器官标注 Callout |
| **映射逻辑** | 头部→认知/抑郁；胸部→心肺慢病；腹部→代谢（糖尿病/高血压）；四肢→ADL/IADL 失能；全身轮廓亮度→综合 FI 分位数 |
| **数据字段** | `cognition`, `r*memrye`, `r*hearte`, `r*stroke`, `r*lunge`, `r*diabe`, `r*hibpe`, `r*arthre`, ADL 六项均值 |
| **设计理由** | 参考图中"Risk & Further Complication"人体标注有效降低非专业观众理解门槛；符合 **Semantic Interaction** 中"利用领域隐喻缩短认知距离"的原则 |
| **交互** | 点击器官区域 → 筛选患该类问题的人群；悬停显示患病率 + 相对风险 RR（相对全国均值） |

> **团队原创贡献：** 将 Rockwood 缺陷累积模型中的 5 域（慢病/ADL/IADL/认知/躯体功能）映射到人体解剖区域，而非照搬糖尿病并发症图。

#### A3 · 核心 KPI 环形图（Donut Chart）

- 展示当年 Robust / Pre-Frail / Frail 占比
- 中央大字显示 **Frail 率** 与 **同比变化箭头**（若 year>2011）
- 理论：环形图适合"部分–整体"关系，但仅用于 ≤4 类分类，避免角度判断误差（Few, 2007）

#### A4 · 慢病共病象形图（Isotype / Unit Chart）

- 10 种慢病按患病率排序，每行 100 个微型人形图标，填充比例=患病率
- 支持"多病共存"高亮：同时患 ≥3 种慢病者用红色图标子集标示
- 理论：**Isotype**（Neurath, 1930s）让抽象百分比具象化，适合答辩海报传播

#### A5 · 分区域箱线图 Small Multiples

| 属性 | 说明 |
|------|------|
| **图表类型** | **箱线图（Box-and-Whisker Plot）** × 小倍数面板 |
| **面板** | 东/中/西 或 31 省（海报模式用东中西 3 面板；交互模式可展开） |
| **编码** | 箱体=IQR，中线=中位数，须=1.5IQR，离群点散点 |
| **理论** | 箱线图是课程重点高级图表，展示**分布形态**（偏态、离群），比柱状图更符合探索性分析（Tukey, 1977） |
| **交互** | Brush 某一箱线 → 联动人体图显示该分位人群特征 |

#### A6 · 多维因素 Horizon 条带图

- 横向展示 SES、睡眠、社交、医疗可及性 4 维的标准化得分对比（城乡两组）
- 可选：点击维度展开为细项条形图（Details-on-Demand）

### 3.4 Page B：多年趋势分析页 `/trends`

**设计目标：** 回答 *"七年间衰弱负担如何演变？谁在恶化？哪些因素驱动了变化？"*

**布局草图：**

```
┌──────────────────────────────────────────────────────────────────────────┐
│  AgeVital · 多年趋势                    [队列: 全样本 / 追踪队列25586]      │
├────────────────────────────────────┬─────────────────────────────────────┤
│  B1 · 投影增长面积图                 │  B2 · 衰弱轨迹桑基图                 │
│  Stacked Area: 三分类人数随时间       │  2011→2013→2015→2018 状态流         │
│  + 折线: Frail率%                    │  (Alluvial / Sankey)                │
├────────────────────────────────────┼─────────────────────────────────────┤
│  B3 · 小倍数地图动画                  │  B4 · 相关矩阵热力图 + 散点矩阵      │
│  4 帧省份 FI 填色（2011/13/15/18）    │  Spearman + 层次聚类重排             │
├────────────────────────────────────┴─────────────────────────────────────┤
│  B5 · 平行坐标图（追踪队列 25586 人 × 4 波特征）                             │
├──────────────────────────────────────────────────────────────────────────┤
│  B6 · 流式图 / 脊线图 (Ridgeline)  FI 分布逐年叠加                          │
└──────────────────────────────────────────────────────────────────────────┘
```

#### B1 · 堆叠面积图 + 折线双编码（Projected Growth 风格）

| 属性 | 说明 |
|------|------|
| **图表类型** | Stacked Area Chart + Line Overlay |
| **编码** | 面积=各衰弱类别绝对人数；折线=Frail 占比 % |
| **参考对应** | 参考图左侧 "Projected growth rate" 面积趋势 |
| **洞察** | 2011→2018 Pre-Frail 面积持续扩大 → **"衰弱蓄水池"效应** |

#### B2 · 交互式桑基图（Sankey / Alluvial）

| 属性 | 说明 |
|------|------|
| **图表类型** | 桑基图（Riehmann et al., 2005） |
| **节点** | 4 波 × 3 类 = 12 节点（NA 单独灰色流） |
| **交互** | 点击流束 → `selectedIds` → 平行坐标高亮；支持对比两条路径 |
| **理论** | 离散状态迁移的最优编码；流宽度=人数（面积通道） |

#### B3 · 小倍数地图动画（Small Multiples Choropleth）

| 属性 | 说明 |
|------|------|
| **图表类型** | **小倍数（Small Multiples, Tufte, 1983）**—— 4 幅中国地图横排 |
| **编码** | 统一色标（Shared Color Scale）确保跨年份可比；年份标注于子图标题 |
| **交互** | 播放/暂停动画；悬停某省显示 4 年 FI 折线 sparkline |
| **理论** | 小倍数通过**分区（Partitioning）**降低动画带来的变化盲视（Robertson et al., 2008） |

#### B4 · 相关热力图 + SPLOM 散点矩阵

- 热力图：Spearman 相关 + 层次聚类排序（课程高级特征）
- 点击单元格 → 展开 2×2 散点矩阵（SPLOM）细节
- 变量覆盖：FI、慢病、ADL、CESD-10、SC_Total、ACE 累计分等

#### B5 · 平行坐标图（Parallel Coordinates）

| 属性 | 说明 |
|------|------|
| **图表类型** | 平行坐标（Inselberg, 1985） |
| **模式** | 每线=一人；按 frailty_cat 着色；Alpha Blending 缓解过绘制 |
| **高级交互** | 轴拖拽重排（Axis Reordering）；轴向 Range Brush；密度模式切换 |
| **理论** | 高维探索经典方法；配合桑基图完成"轨迹→特征"逆向溯源 |

#### B6 · 脊线图 / 小提琴图（Ridgeline / Violin）

| 属性 | 说明 |
|------|------|
| **图表类型** | **Ridgeline Plot**（Joy Plot）或 Violin Plot |
| **编码** | 每年 FI 分布的核密度曲线纵向堆叠 |
| **理论** | 比直方图更优雅地展示分布形态随时间漂移；尾部增厚=高风险人群扩大 |
| **炫技点** | 课程中较少小组使用，可体现对分布数据的深入理解 |

---

#### B7 · 散点/气泡图（Scatter / Bubble）

| 属性 | 说明 |
|------|------|
| **图表类型** | **散点图 + 气泡图**（双模式可切换） |
| **模式1 Scatter** | X=focusDimension Y=FI，按 frailty_cat 着色 |
| **模式2 Bubble** | X=抑郁（与FI最强相关 r=0.43） Y=ACE，气泡大小=FI，颜色=FI三级（🔴衰弱 ≥0.25 / 🟡衰弱前期 0.10-0.25 / 🟢健壮 ≤0.10） |
| **数据过滤** | ACE=0 的记录被剔除（缺失值），Y轴固定 50-100 |
| **交互** | Hover 显示详细数值（抑郁、ACE、FI、衰弱分类） |
| **理论** | 气泡图将 FI 大小+颜色双通道编码结果变量，X/Y 分别放置与FI相关性最高的两个预测因子，形成"预测→结局"视觉叙事 |

## 4. 可视化设计理论支撑

### 4.1 信息寻求 Mantra（Shneiderman, 1996）

| 层次 | Page A | Page B |
|------|--------|--------|
| **Overview** | 地图 + KPI 环图 | 面积图 + 桑基图 |
| **Zoom & Filter** | 省份点击、箱线 Brush | 流束选择、平行坐标 Brush |
| **Details-on-Demand** | 器官 callout 展开、因素条带细节 | SPLOM 展开、个体 FI 曲线 |

### 4.2 视觉通道选择（Mackinlay, 1986; Cleveland & McGill, 1984）

| 数据类型 | 通道 | 使用场景 |
|---------|------|---------|
| 分类（衰弱类别） | 色相 | 桑基节点、平行坐标线条 |
| 有序（FI 分位数） | 亮度/饱和度 | 地图填色、人体轮廓 |
| 定量（患病率） | 位置、长度 | 箱线图、条形图 |
| 时间 | 水平位置 | 面积图 x 轴、桑基列 |
| 地理 | 空间位置 + 颜色 | Choropleth |
| 分布 | 箱体/密度形状 | 箱线图、脊线图 |

### 4.3 高级图表选用说明（对应课程"炫技"要求）

| 图表 | 难度 | 分析价值 | 为何不用简单替代 |
|------|------|---------|----------------|
| **箱线图 Small Multiples** | ★★★★ | 比较区域 FI 分布形态 | 柱状图只给均值，掩盖偏态与离群 |
| **人体隐喻图** | ★★★★★ | 领域语义降维 | 纯表格无法建立"身体—指标"直觉 |
| **桑基图** | ★★★★ | 状态迁移路径 | 折线图无法表达离散状态流转 |
| **脊线图** | ★★★★ | FI 分布逐年漂移 | 单年直方图无法纵向对比 |
| **象形图 Isotype** | ★★★ | 共病负担传播 | 数字百分比缺乏冲击力 |
| **平行坐标** | ★★★★★ | 高维亚群筛选 | 散点图仅能做二维 |

### 4.4 多视图协调（Roberts, 2007）

双页共享 **全局状态仓库（Global Store）**：

```typescript
interface GlobalState {
  selectedYear: 2011 | 2013 | 2015 | 2018;
  selectedProvince: string | null;
  selectedIds: Set<string>;
  frailtyFilter: ('robust'|'pre-frail'|'frail')[];
  cohortMode: 'all' | 'tracked';  // 全样本 vs 25586 追踪队列
}
```

**跨页联动：** 在 Page B 桑基图中选中"快速恶化路径"人群后，跳转 Page A 并自动设置 `year=2018`、`selectedIds=...`，人体图与箱线图展示该子群体特征——实现**跨页面 Brushing & Linking**。

## 5. 案例研究（Case Study）

### 案例 1：从地图到人体——西部农村高危画像（Page A）

**流程：**
1. 打开 `/snapshot?year=2018`，地图显示西部省份 FI 偏高
2. 点击 **四川省** → 箱线图显示该省 FI 中位数 0.14，东中部约 0.09
3. 人体图联动：代谢域（高血压+糖尿病）标注 28.3%，高于全国 22.4%
4. 象形图显示 ≥3 种慢病共存比例达 19%

**洞见：** 西部农村衰弱负担呈现"代谢–功能"双高模式，提示干预应聚焦慢病管理与 ADL 支持的综合策略。

### 案例 2：七年"蓄水池"——Pre-Frail 的预警价值（Page B）

**流程：**
1. 面积图显示 Pre-Frail 人数 2011→2018 从 4,921→6,435（追踪队列口径）
2. 桑基图点击 `Robust@2011 → Pre-Frail@2013 → Frail@2018` 流束
3. 平行坐标显示该路径人群：低教育 + 高 CESD-10 + 低 SC_Engagement
4. 脊线图显示该群体 FI 分布逐年右移

**洞见：** Pre-Frail 是可干预窗口；系统在 30 秒内完成"趋势→路径→特征"三层穿透，传统队列研究需数月。

### 案例 3：Poster 叙事——一图答辩

合成大图用于答辩开场 30 秒：评委先看到趋势区得出"问题在恶化"，再看到快照区得出"问题在身体与空间上的具体表现"，随后演示交互页面深化。

- 桑基：节点限 12 个，流束 <50 条，性能无忧
- 海报：静态截图，无交互性能要求
