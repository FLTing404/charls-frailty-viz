## 中国中老年人衰弱状态及多维驱动因素可视分析

> 浙江大学 · 数据可视化导论 · 课程大作业
>
> CHARLS 2011–2018 四波次纵向队列 · 26 项缺陷累积衰弱指数

# 一、设计需求

## 1.1 项目背景

人口老龄化是中国当前面临的重大社会挑战。截至 2018 年，中国 60 岁以上人口占比已达约 17.9%，且老龄化速度持续加快。**衰弱（Frailty）**是老年医学的核心概念，指老年人因多系统生理储备下降而导致的对应激事件的脆弱性增加，是失能、住院和死亡的重要前兆。与单一的疾病诊断不同，衰弱是多个器官系统渐进性退化的累积结果，其多维性、动态性和地域差异性使其天然适合用可视分析方法进行探索。

CHARLS（中国健康与养老追踪调查）是目前中国最具代表性的中老年纵向队列，自 2011 年起每 2–3 年追踪约 17,000 名 45 岁以上中老年人，涵盖健康状况、社会经济、生活方式、认知功能等广泛领域。基于 26 项缺陷累积模型构建的衰弱指数（Frailty Index, FI）为研究中国老年衰弱的时空演化提供了可靠的数据基础。

近年来，越来越多研究揭示了童年不良经历（Adverse Childhood Experiences, ACE）、睡眠质量、社会参与、抑郁症状、社会经济地位等因素与老年衰弱之间的复杂关联，但这些研究多以统计表格和单一效应量呈现结果，难以直观展现出多维因素间的相互作用模式、空间异质性以及个体间差异。

## 1.2 分析任务定义

AgeVital 系统围绕以下四个核心分析任务设计：

### 任务 T1：衰弱空间分布的跨期对比

**问题**：中国各省份的衰弱率呈现怎样的空间格局？东西部差异有多大？这种差异在 2011–2018 年期间如何演变？

**可视化需求**：需要一个能同时呈现地理分布与数值对比的视图，支持年份切换且保持颜色映射一致，支持省份选择以触发下游分析。

### 任务 T2：缺陷共病网络与空间叠加

**问题**：26 项衰弱缺陷（慢性病、ADL、IADL、体能、感官、自评）之间存在怎样的共现关系？不同缺陷在各省/各城市的患病率分布如何？

**可视化需求**：需要一个展示缺陷共现关系的网络视图，并能按类别筛选；需要将缺陷的空间分布与地图联动，实现从"网络结构"到"地理分布"的钻取。

### 任务 T3：个体级多维驱动因素轨迹探索

**问题**：ACE、睡眠、抑郁、FI、社会经济地位等十维因素在个体层面如何分布？某些子群（如高 ACE + 高抑郁 + 高 FI）是否具有独特的驱动因素画像？不同省份的驱动因素结构有何差异？

**可视化需求**：需要一个能展示高维数据分布的视图，支持交互式刷选和子群联动；需要多个互补视图（热力图、散点图、旭日图、和弦图）从不同角度展示刷选子群的特征。

### 任务 T4：衰弱状态的时序转化追踪

**问题**：个体在四个波次间经历了怎样的衰弱状态变化（健壮 → 衰弱前期 → 衰弱 → 失访/死亡）？哪些省份的衰弱进展速度异常？衰弱逆转（recovery）是否与高水平社会参与相关？

**可视化需求**：需要一个能清晰展示四个波次间状态流转的视图，标注出"异常加速"和"逆转恢复"两类特殊流向。

## 1.3 为什么需要可视化方法

上述分析任务无法仅通过统计表格或机器学习模型解决，原因如下：

1. **空间异质性**：衰弱率的省际差异存在显著的空间自相关，且与区域社会经济条件、医疗资源分布、早年生活条件等结构性因素相关。统计模型可以给出效应量（如 OR），但无法直观展示"哪些相邻省份构成了高风险聚集区"以及"东西部梯度如何在四个波次间收窄"。

2. **多维交互**：ACE、抑郁、社会参与等因素对衰弱的影响并非独立作用，存在中介效应（抑郁中介约 29% ACE→衰弱效应）和调节效应（社会参与缓冲 ACE 效应）。散点图 + 平行坐标的组合可以直观揭示这些交互模式。

3. **个体异质性**：同一省份、同一 ACE 水平的个体可能具有截然不同的衰弱轨迹。平行坐标图的刷选能力允许研究者基于任意维度范围定义子群，即时观察子群在其他维度的分布特征。

4. **时序动态**：个体在四个波次间的衰弱状态转化是一个复杂过程，桑基图以流向带宽直观展示"健壮→衰弱前期→衰弱→失访"的主流路径与"衰弱→衰弱前期→健壮"的逆转路径，统计转移矩阵难以替代。

## 1.4 数据说明

| 属性 | 内容 |
|------|------|
| 数据来源 | CHARLS 2011 / 2013 / 2015 / 2018 四波次 |
| 数据规模 | 约 17,000 人/波次，覆盖 28 省份（含直辖市），约 150 个城市 |
| 核心指标 | 衰弱指数（FI，基于 26 项缺陷累积）、10 维驱动因素得分 |
| 空间粒度 | 省级（choropleth）+ 城市级（气泡叠加） |
| 时间粒度 | 波次对比（PP 差值） |
| 数据格式 | 原始 .dta / .csv → Python 预处理 → 44 个 JSON → 前端 fetch |
| 数据许可 | CHARLS 数据需向北京大学国家发展研究院申请；本仓库仅含聚合后 JSON |

# 二、设计介绍

## 2.1 系统总览

AgeVital 采用**双页面结构**，分别对应两条分析主线：

- **快照页（Snapshot）**：聚焦**空间维度**——衰弱率省域分布、缺陷共病网络、城市级气泡叠加
- **轨迹页（Trajectories）**：聚焦**个体维度**——十维驱动因素平行坐标、相关性热力图、衰弱状态桑基流转、人群构成旭日图、因素关联和弦图

两页面通过**省份点击跳转**实现语义联动：快照页点击某省份 → 自动跳转轨迹页并设置省份筛选 → 轨迹页所有视图同步过滤为该省数据。

## 2.2 可视化设计

### 2.2.1 快照页视图设计

#### V1: 中国省级 Choropleth 地图

- **视觉通道**：颜色（sequential color ramp：淡米色 → 朱砂红）编码衰弱率（0.086–0.463）
- **固定色阶**：所有年份共用 global min/max，确保跨年颜色可比
- **交互**：hover 显示 tooltip（省份名、衰弱率、FI、样本量、人口结构）；点击省份触发跨页跳转
- **叠加层**：点击共病网络节点后，地图叠加城市级气泡散点（气泡大小 = 该城市该缺陷患病率）
- **背景**：世界地图作为底图参考（墨色半透明）

#### V2: 共病力导向图（Force-Directed Graph）

- **视觉通道**：节点大小 = 患病率，边粗细 = φ 相关系数（共现强度），节点颜色 = 缺陷类别（6 类：慢性病、自评、ADL、IADL、体能、感官）
- **布局算法**：ECharts 力导向布局，节点间斥力参数微调以避免重叠
- **交互**：图例点击切换类别显示/隐藏；点击节点 → 地图叠加城市气泡 + 左侧排名栏切换为该缺陷
- **设计理由**：力导向图天然适合展示共病网络——物理关联的缺陷（高血压↔心脏病↔糖尿病）自动聚拢，视觉上形成"慢性病簇""ADL 簇""体能簇"等自然分组

#### V3: 省份排名柱状图

- **视觉通道**：柱长 = 衰弱率（或选中缺陷的患病率），颜色渐变从竹青（低）→琥珀（中）→朱砂（高）
- **交互**：点击共病节点后自动切换为该缺陷的各省患病率排名
- **设计理由**：choropleth 地图适合"找位置"，但难以精确比较数值——排名柱状图作为补充，允许精确读数和排序

### 2.2.2 轨迹页视图设计

#### V4: 相关性热力图

- **视觉通道**：颜色（蓝→白→红 diverging colormap）编码 Spearman ρ（-0.5～+0.5）
- **数据来源**：对当前省份（或全国）的个体记录动态计算 Spearman 秩相关矩阵
- **交互**：点击单元格设置 focusDimension → 平行坐标对应轴高亮；只显示 |ρ| ≥ 0.08 的数值标签

#### V5: 平行坐标图

- **视觉通道**：10 条垂直轴（ACE / 睡眠 / 社会联系 / 抑郁 / FI / SES / 医疗 / 社交参与 / 社会资本 / 物质条件），每条折线 = 一个人；颜色按衰弱状态（健壮=竹青 / 衰弱前期=琥珀 / 衰弱=朱砂）
- **缺值处理**：若某维度缺值 > 70%，自动隐藏该轴（适配省份模式下数据稀疏的维度的隐含模式）

- **交互**（关键）：
  - **点击热力图单元格** → 对应轴标签变朱砂色加粗，轴线加粗
  - **轴上拖拽框选** → 基于框选区间过滤个体 ID → brushedIds 通过 Zustand 传递 → B1/B2 视图同步更新
  - **多轴框选取交集**（如框选 ACE 高分 + 抑郁高分 + FI 高分 → 识别"三重风险"子群）
  - **再次框选空区域** → 清除刷选，恢复全集

#### V6: 四波次桑基图

- **视觉通道**：流向带宽 = 人数（千人为单位），颜色按出发状态；异常标签标注"跳跃恶化"和"逆转恢复"流向
- **结构**：4 层（2011 / 2013 / 2015 / 2018），每层 4 种状态（健壮 / 衰弱前期 / 衰弱 / 失访）
- **条件概率**：hover 显示源→目标的转移概率

#### V7: 气泡图（抑郁 × ACE, size = FI）

- **视觉通道**：X 轴 = 抑郁得分，Y 轴 = ACE 得分，气泡大小 = FI 衰弱指数，颜色 = 衰弱状态分类
- **交互**：散点悬停显示个体详细值；只受平行坐标刷选控制（不独立筛选）
- **焦点模式**：若 focusDimension 设置，地图标轴替换为焦点维度

#### V8: 旭日图（三层：衰弱状态 → 性别 → 城乡）

- **视觉通道**：内圈 = 衰弱状态（健壮/衰弱前期/衰弱），中圈 = 性别（男/女），外圈 = 城乡；扇区弧长 = 人数
- **设计理由**：揭示人口构成中的结构差异——例如"衰弱群体中女性占比是否显著高于男性"

#### V9: 和弦图（十维驱动因素关联）

- **视觉通道**：弦宽 = Spearman |ρ|；外环弧长 = 维度"总关联强度"
- **设计理由**：和弦图比热力图更强调关系网络性质，适合发现"哪些维度构成了一个共变模块"

## 2.3 多视图协调设计

### 2.3.1 Brushing & Linking 架构

```

                    │   相关性热力图点击    │

                             ▼
              ┌──────────────────────────────┐
              │      平行坐标图               │

                     │ Zustand trajectoryStore
                     ▼
     ┌───────────────┼───────────────┬───────────────┐
     ▼               ▼               ▼               ▼
  B1-气泡图      B1-桑基图       B2-旭日图       B2-和弦图
 (散点过滤)    (流向过滤)     (扇区过滤)     (仅显示刷选子群)
```

### 2.3.2 跨页面 Semantic Zoom

```
快照页：全国空间概览
   │
   ├── 点击省份 → 轨迹页（省份级个体分析）
   │                  │
   │                  ├── 平行坐标框选 → 子群级特征分布
   │                  │
   │                  └── 桑基图 → 子群流转分析
   │
   └── 点击共病节点 → 地图城市气泡（城市级细节）
```

### 2.3.3 联动关键设计点

1. **省份选择**：存储在 `globalStore.province`，快照页和轨迹页共享同一 Zustand store，省份变化时轨迹页自动重新加载该省数据
2. **URL 参数传递**：快照页 → 轨迹页通过 `?province=Sichuan` 传递，支持直接分享 URL
3. **刷选 ID**：存储在 `trajectoryStore.brushedIds`，仅在轨迹页内部使用，不影响全局筛选
4. **焦点维度**：`trajectoryStore.focusDimension` 由热力图点击设置，影响平行坐标轴高亮 + 气泡图坐标轴选择

## 2.4 AI 辅助分析设计

### 2.4.1 异常发现面板

- **触发时机**：年份切换或省份选择时自动运行
- **计算流程**：计算全国 + 各省衰弱率变化 → 识别偏离均值 > 1.5σ 的异常省份 → 构造 context-aware prompt → 调用 DeepSeek（或使用预生成预设）
- **输出格式**：headline + nationalOverview + anomalies[] + attention + driverHypothesis
- **预设策略**：`AI_PRESET_ENABLED = true` 时使用 `preGenerated.ts` 中的预生成分析，涵盖 National × 3 时间段 + 6 个代表性省份，无需 API 调用即可展示分析能力

### 2.4.2 智能问答 Agent

- **知识注入**：CHARLS 衰弱研究 8 篇核心文献的关键发现 + 2011–2018 年中国重大健康政策/事件知识库
- **上下文感知**：自动注入当前年份、省份、全国衰弱率变化、top 异常省份等数据上下文
- **交互设计**：快速提问按钮 + 自由文本输入；回答以结构化 Markdown 渲染（粗体关键结论、代码框数值、分条列出）
- **安全护栏**：强调所有变量为连续值（禁止离散阈值），引导用户在可视化视图中验证

## 2.5 视觉风格设计

系统采用**水墨（Ink-Wash）中式美学主题**，设计原则：

| 元素 | 设计选择 | 理由 |
|------|---------|------|
| 底色 | 宣纸色系（#F7F3EB, #FAF6F0） | 低亮度暖色调，减少长时间使用的视觉疲劳 |
| 文字 | 思源宋体（Noto Serif SC）+ Inter | 标题用衬线体现传统感，数据用无衬线保证可读性 |
| 语义色 | 竹青（健壮）/ 琥珀（衰弱前期）/ 朱砂（衰弱） | 中国传统色谱，色觉障碍友好（亮度差异显著） |
| 边框 | 0.5px 细线 + 背面模糊 | 模仿水墨画"留白"与"边界晕染"效果 |
| ECharts 主题 | 注册自定义 'ink-wash' 主题 | 统一所有图表的 tooltip、坐标轴、图例样式 |

# 三、案例展示（Case Study）

以下两个案例展示如何使用 AgeVital 系统进行完整的数据探索——从宏观空间模式到微观个体机制，从自主可视化操作到 AI 辅助的文献知识注入。每个案例包含**分析目标、操作步骤、观察发现、洞察解释、配图说明**。

---

## Case Study 1：东西部衰弱率梯度加剧——西部"越来越红"，慢性病同步恶化

### 分析目标

CHARLS 区域分析文献一致报告西部省份（贵州、甘肃、云南）衰弱率最高，东部沿海（上海、江苏、浙江）最低。本案例不仅验证这一"东西梯度"，更关注一个文献中较少触及的问题：**西部是否不仅在基线更高，而且恶化速度更快？**同时，以关节炎（arthre）为代表，验证慢性病负担是否也呈现同步的东西部差距。

### 操作步骤

1. 打开快照页 `/snapshot`，默认显示 2018 年数据；观察中国 choropleth 地图——西部省份呈深朱砂色（高衰弱率），东部呈淡米色（低衰弱率）
2. 依次切换年份按钮：2011 → 2013 → 2015 → 2018，每次切换后观察颜色变化的幅度——重点注视四川、青海、新疆的颜色加深速度
3. 查看轨迹页 WaveSelector 左侧"发现面板"，阅读各时间段 AI 生成的全国变化分析（如 2011→2013 分析指出"西部省份初显加速迹象"）
4. 返回快照页，在右侧力导向图中点击图例筛选至仅保留"慢性病"类别 → 找到**关节炎（arthre）**节点 → 点击节点
5. 观察地图上叠加的城市级气泡（气泡大小 = 各城市关节炎患病率）——注意气泡在西部城市（重庆、成都、昭通）和东部城市（上海、杭州）的直径差异
6. 切换年份 2011/2013/2015/2018，对比关节炎气泡的时空变化

### 观察发现

**衰弱率方面**（来自 `map_province_{year}.json` 四波次数据）：

| 类别 | 省份示例 | 2011 衰弱率 | 2018 衰弱率 | 变化幅度 |
|------|---------|------------|------------|---------|
| **西部** | 新疆 | 23.6% | 44.3% | **+20.8 pp** |
| | 青海 | 11.1% | 27.4% | **+16.3 pp** |
| | 广西 | 10.0% | 20.8% | **+10.8 pp** |
| | 内蒙古 | 18.3% | 28.9% | **+10.6 pp** |
| | 四川 | 21.3% | 27.6% | +6.3 pp |
| **东部** | 上海 | 11.3% | 8.8% | **−2.5 pp（下降！）** |
| | 江苏 | 13.0% | 13.8% | +0.8 pp |
| | 北京 | 12.9% | 13.2% | +0.3 pp |
| | 浙江 | 7.1% | 9.8% | +2.6 pp |

关键发现：
- 西部省份的衰弱率变化幅度系统性高于东部——新疆 +20.8 pp、青海 +16.3 pp，而上海甚至**下降**了 2.5 pp
- 新疆、青海虽然样本量较小（n=106、157），但其变化幅度之大仍值得警惕；四川（n=1748，大样本）同样录得 +6.3 pp 的显著上升
- 在四波次逐一切换时，肉眼即可观察地图上西部省份朱砂色的**持续加深**——西部"越来越红"

**关节炎方面**（来自 `deficit_province_{year}.json` 四波次数据）：

| 年份 | 西部平均患病率 | 东部平均患病率 | 西/东比值 |
|------|-------------|-------------|----------|
| 2011 | 41.1% | 23.2% | **1.77×** |
| 2013 | 42.4% | 25.1% | **1.69×** |
| 2015 | 52.9% | 33.5% | **1.58×** |
| 2018 | 46.1% | 28.7% | **1.61×** |

关节炎患病率 Top/Bottom：
- **常年最高**：重庆（55–68%）、四川（54–68%）、云南（48–60%）——全部位于西部
- **常年最低**：上海（16–26%）、北京（20–23%）、浙江（18–25%）——全部位于东部

值得注意的是，2015 年西部关节炎平均飙升至 52.9%（四川 67.5%、重庆 67.6%），几乎每两个老年人就有一个报告关节炎，而同期上海仅 25.9%。

### 洞察解释

1. **东西部"双重分化"**：西部不仅在基线衰弱率上更高，其**恶化速度也系统性更快**——这不是简单的"起点差异"，而是"加速度差异"。将地图从 2011 切换到 2018 时，西部的颜色变化幅度（色阶跃迁）远大于东部，直观展示了这一"加速度差异"。

2. **关节炎作为慢性病负担的缩影**：关节炎的西部/东部比值（1.6–1.8×）与衰弱率比值（约 1.3–1.5×）高度一致。关节炎本身既是衰弱指数（FI）的构成缺陷之一，也是导致活动减少→肌肉萎缩→功能衰退的因果链起点。CHARLS 文献指出，关节炎的慢性疼痛会直接限制社会参与和身体活动，而低社会参与（European Review of Aging and Physical Activity, 2024）又进一步抑制衰弱逆转——形成"关节炎→活动减少→社会隔离→衰弱加速"的恶性循环。

3. **政策含义**：西部省份在老龄化进程加速的背景下，面临慢性病管理资源不足和衰弱率快速上升的双重挑战。关节炎作为一种可管理但不可治愈的慢性病，其高患病率提示西部基层医疗在疼痛管理、康复训练和适老化改造方面存在巨大缺口。

## Case Study 2：AI 引导的抑郁中介效应验证——以四川省为例

### 分析目标

近年 CHARLS 研究中，**Zhou 等人（2024）**（N=3,491，随访 8 年）是一个里程碑式发现：**抑郁症状中介了 29.1% 的 ACE→衰弱效应**。这意味着童年不良经历并不直接"导致"衰弱，而是约三分之一通过引发抑郁症状间接传导。然而，这一结论来自全样本统计建模，在具体省份层面是否成立、在系统中如何交互式验证，是可视化分析需要回答的问题。

本案例展示一个完整的人机协作流程：**用户向 AI 提问 → AI 引用文献并建议筛选策略 → 用户在平行坐标中执行筛选 → 视图联动验证假说**。我们选择**四川省（Sichuan）**作为分析对象——数据预处理显示，四川省是全国样本量最大的省份（N=1,436），且在"ACE×Dep×FI"中介路径上具有极其清晰的信号，与 Case Study 1 中揭示的"西部高衰弱负担"形成叙事闭环。

### 四川省的选择依据

在系统后端数据（`driver_records_2018.json`）中，四川省 1,436 条个体记录（全国 28 省份中最多）呈现以下特征：

| 指标 | 四川省 (N=1,436) | 全国 (N=28,000+) |
|------|-----------------|-----------------|
| ACE×抑郁 Spearman ρ（a 路径） | +0.044 | +0.014 |
| 抑郁×FI Spearman ρ（b 路径） | **+0.456** | +0.427 |
| ACE×FI Spearman ρ（直接，c' 路径） | +0.070 | +0.028 |
| FI 均值 | 0.178 | — |
| **高 ACE + 高抑郁**子群 FI 均值 | **0.294** | — |
| 其余人群 FI 均值 | **0.169** | — |
| **高 ACE + 低抑郁**子群 FI 均值 | **0.091** | — |
| **子群 FI 高出比例**（高vs其余） | **+75%** | — |
| **韧性对比**（高抑郁 vs 低抑郁） | **3.25×** | — |

这一数据模式极其清晰地验证了 Zhou 等人（2024）的**中介假说**：
- **ACE→Dep 路径**（a 路径）：正相关 ρ=+0.044——ACE 高的个体抑郁得分确实偏高
- **Dep→FI 路径**（b 路径）：非常强的正相关 ρ=**+0.456**——抑郁是 FI 最有力的心理预测因子之一
- **ACE→FI 直接路径**（c' 路径）：弱相关 ρ=+0.070——ACE 对 FI 的直接影响远小于经由抑郁的间接影响
- **两群 FI 差异**：高 ACE+高抑郁子群的 FI（0.294）比其余人群（0.169）高出 75%
- **韧性证据**：高 ACE+**低**抑郁子群的 FI（0.091）**仅为高 ACE+高抑郁子群的 1/3**——同样是经历过高 ACE 的个体，取决于是否发展出抑郁症状，晚年衰弱风险相差 3.25 倍

### 操作步骤

#### 第一步：向 AI 提问，获取文献引导

1. 进入轨迹页 `/trajectories`，选择 2018 年
2. 默认显示全国视图，在 WaveSelector 右侧面板切换到"**问答**"tab
3. 在输入框中输入："**有哪些证据表明抑郁在ACE和衰弱之间起中介作用？**"
4. AI（chatAgent）回复，自动引用 `frailtyKnowledge.ts` 中的结构化文献知识（RAG）：

> **AI 回复示例**（来自系统 `chatAgent.ts` 的 RAG 注入）：
>
> "根据 **Zhou et al., 2024**（N=3,491，CHARLS 回顾性队列，随访 8 年）：家庭暴力（**OR=1.63**）、父母残疾（**OR=1.34**）、不安全社区（**OR=1.57**）独立预测衰弱发生。其中，**抑郁症状中介了 29.1% 的 ACE→衰弱效应**。此外，**JAMA Network Open, 2022**（N=11,568）确认每条 ACE 增加 20% 衰弱风险（**OR=1.20**）。
>
> 建议操作：在平行坐标图的 ACE 轴和抑郁轴上分别框选高分段，观察框选后子群的 FI 分布是否显著右偏——这将直接验证抑郁中介假说在你所选省份的表现。"

5. 继续提问："**哪个省份最适合验证这个中介效应？**"
6. AI 分析当前数据上下文（已注入各省变化数据），回复建议关注**四川省**——理由是：四川是全国样本量最大的省份（N=1,436），且作为 Case Study 1 中揭示的西部高衰弱负担省份，验证中介效应具有更强的现实意义

#### 第二步：切换到四川省，执行平行坐标框选

7. 点击右侧省份地图中的"四川"（或从快照页点击四川跳转）→ 所有视图切换为四川数据
8. 在热力图（R1）中点击"ACE × 抑郁"单元格 → 平行坐标图的 ACE 轴和抑郁轴同时变红加粗高亮
9. 在平行坐标图的 ACE 轴（第 1 轴）上拖拽框选右侧高分段（四川 ACE Q3=77，约在轴线右 1/3 处开始拖拽）
10. 在抑郁轴（第 4 轴）上继续拖拽框选高分段（四川抑郁 Q3=14，约在轴线右半段）→ 取交集，得到"高 ACE + 高抑郁"子群
11. 观察底部状态栏："已刷选 112 / 1,436 人"（约占四川样本的 7.8%）
12. 查看下方 B1 气泡图和 B2 旭日图——它们已自动切换为刷选子群的分布

#### 第三步：对比验证（重点——韧性效应）

13. 在 B1 面板切换到**气泡图**：X=ACE，Y=抑郁，气泡大小=FI——刷选子群的 112 个点集中在右上角，气泡（FI）普遍巨大
14. 在 B2 面板切换到**旭日图**：观察刷选子群的衰弱状态构成——**frail 占比 58.0%，robust 仅 12.5%**（四川全样本 frail 仅 25.7%，robust 约 38%）
15. 点击平行坐标图空白区域**清除刷选** → 恢复全样本 → B1/B2 切回全样本分布——对比"刷选子群 vs 全样本"的巨大差异

17. 观察底部状态栏："已刷选 84 / 1,436 人"
18. 查看 B2 旭日图：**frail 占比仅 3.6%，robust 占比高达 65.5%**——即使 ACE 很高，只要抑郁水平低，衰弱风险反而不高于常人
19. B1 气泡图：这 84 个点集中在**右下角**（高 ACE + 低抑郁），气泡普遍非常小

20. 再次在"问答"tab 输入："**四川数据显示，同样是高ACE，高抑郁组FI=0.294、frail=58%，低抑郁组FI=0.091、frail=3.6%，相差3.25倍。这和Zhou 2024的29.1%中介效应一致吗？**"
21. AI 回复确认一致性并补充解释：

> **AI 回复示例**：
>
> "这是一个非常有说服力的发现。四川数据极其清晰地展示了 **Zhou et al. (2024)** 抑郁中介假说的两段路径：
>
> 1. **ACE→抑郁**（a 路径）：ACE≥Q3(77) 的个体中，确实有一部分人抑郁得分≥Q3(14)（约 112 人），也有一部分人抑郁得分≤Q1(4.1)（约 84 人）——ACE 并不必然导致抑郁
> 2. **抑郁→FI**（b 路径）：抑郁得分是 FI 的最强心理预测因子之一（ρ=+0.456），这解释了为什么同样是高 ACE，抑郁高的那群 frail=**58%**，而抑郁低的那群 frail 仅 **3.6%**
>
> 3.25 倍的差距意味着：**ACE 对衰弱的推动效应几乎完全经由抑郁传导**——如果阻断了 ACE→抑郁这条通路，ACE 本身对衰弱的直接影响相当有限（c' 路径 ρ=+0.070）。这一可视化发现比统计论文中报告的"中介比例 29.1%"更加直观有力——因为它让你亲手构建了这两个子群并亲眼看到了差距。"

### 观察发现

| 对比维度 | 四川全样本 (N=1,436) | 高 ACE + 高抑郁 (N=112) | 高 ACE + **低**抑郁 (N=84) | 高 vs 低比值 |
|---------|---------------------|------------------------|--------------------------|------------|
| FI 均值 | 0.178 | **0.294** | **0.091** | **3.25×** |
| frail 占比 | 25.7% | **58.0%** | **3.6%** | **16×** |
| robust 占比 | ~38% | 12.5% | **65.5%** | 0.19× |
| ACE×FI 直接 ρ | +0.070 | — | — | — |
| 抑郁×FI ρ | **+0.456** | — | — | — |

> 注：高/低分组基于 ACE≥Q3(77) 与 抑郁≥Q3(14) / 抑郁≤Q1(4.1)。数据来自 `driver_records_2018.json`。

四层递进验证：
1. **中介路径的两端都成立**：ACE 与抑郁正相关（ρ=+0.044），抑郁与 FI 非常强相关（ρ=+0.456），两段关联都成立
2. **直接效应远小于间接效应**：ACE×FI 直接关联（ρ=+0.070）远弱于抑郁×FI（ρ=+0.456），提示 ACE→衰弱的主要通路是经由抑郁而非直接作用
3. **韧性效应"天花板级"清晰**：高 ACE + 低抑郁子群的 FI（0.091）**甚至远低于**四川全样本均值（0.178）和全国均值——如果 ACE 没有触发抑郁，晚年衰弱风险极低
4. **衰弱状态几乎"二元化"**：同样是高 ACE，高抑郁群 58% frail vs 低抑郁群 3.6% frail——相差 16 倍，这在健康研究中属于极罕见的效应量

### 洞察解释

1. **中介假说的可视化验证**：平行坐标图 + 热力图的联动使得"ACE→抑郁→衰弱"的三步因果链变得可操作——用户在热力图中确认关联方向 → 在平行坐标中定义子群 → 在旭日图/气泡图中验证结果。这与纯统计方法（阅读一个 β 系数）形成了质的差异：用户**亲手构建了子群并亲眼看到了 FI 分布的变化**。

2. **韧性（resilience）的强力证据**：四川数据给出了比任何现有文献都更直观的韧性证据。**高 ACE + 低抑郁子群的 FI=0.091，frail 仅 3.6%——这意味着即使童年经历了高水平的逆境，只要在生命历程中没有发展出严重的抑郁症状，晚年衰弱风险不仅不高于常人，甚至可能更低**。这一发现具有直接的干预指导意义：对高 ACE 群体进行抑郁筛查和早期心理干预，可能比直接针对衰弱本身的干预更有效。

3. **叙事闭环**：四川既是 Case Study 1 中西部高衰弱负担的典型案例，也是 Case Study 2 中揭示抑郁中介和韧性效应的最佳载体——这构成了完整的叙事弧：从"问题在哪里"（西部衰弱越来越高，关节炎越来越重）到"机制是什么"（ACE→抑郁→衰弱的中介路径）到"干预方向在哪里"（阻断 ACE→抑郁传导，激活韧性）。

4. **AI 的角色**：AI 充当"文献导航员"——用户提出分析意图（"验证抑郁中介"），AI 引用具体文献（Zhou 2024、JAMA Network Open 2022）并提供可操作的建议（"在 ACE 和抑郁轴上框选高分段"），用户随后在可视化视图中独立完成验证操作。AI 的回答并不替代分析者的判断——分群、框选、对比高抑郁 vs 低抑郁——这些关键分析步骤由用户自主完成。

## 4.2 团队独立决策 vs 模型建议

### 由团队独立做出的核心决策

1. **分析任务定义（T1–T4）**：四个核心分析任务完全由团队基于 CHARLS 文献阅读和研究问题自主定义。我们在阅读 JAMA Network Open (2022)、Zhou et al. (2024)、Child Abuse & Neglect (2025) 等文献后，识别出"空间分布→个体轨迹→因素关联→时序转化"四级分析递进关系。

2. **双页面结构（Snapshot + Trajectories）**：团队自主决定将"空间分布"和"驱动因素"分别放在两个页面，而非单页多面板。理由是：空间分析面向"where"（地理模式），驱动因素分析面向"why"（因果机制），两者分析粒度不同——前者是省级/城市级聚合，后者是个体级微观数据。

3. **平行坐标 + 热力图 + 桑基 + 气泡的四联动设计**：热力图→focusDimension→平行坐标轴高亮→框选→brushedIds→B1/B2 联动的链路是团队自主设计，目的是实现"从宏观关联→焦点变量→子群定义→构成验证"的递进分析流程。

4. **共病网络→城市气泡的钻取交互**：点击力导向图节点 → 地图叠加城市级气泡的设计灵感来自 Shneiderman 的 Visual Information Seeking Mantra（"Overview first, zoom and filter, then details-on-demand"），但具体的"从网络结构钻取到地理分布"的视角切换是团队针对衰弱缺陷多维特性做的创新。

5. **水墨（Ink-Wash）视觉主题**：选择中国传统文化美学风格是团队的设计决策。在颜色通道的选择上，我们特别注意了色觉障碍友好性——朱砂（衰弱）、琥珀（衰弱前期）、竹青（健壮）的亮度差异足够大，在灰阶下仍可区分。

6. **AI 预设（preGenerated.ts）策略**：团队决定使用预生成 + 离线回退的策略，而非完全依赖实时 API 调用。理由是：(1) 保证离线可用性和稳定性；(2) 内容质量可控——预设文本经过人工审核和文献交叉验证；(3) 预生成覆盖所有关键场景（National × 3 时间段 + 6 个代表性省份）。

### 来自模型建议但经团队评估后采纳的决策

1. **Zustand 双 Store 结构**：Claude 建议将全局筛选（year, province）和轨迹页内部状态（focusDimension, brushedIds）分拆为两个独立 Store，团队评估后采纳——因为全局筛选需要跨页面共享，而刷选 ID 仅在轨迹页内有效。

2. **React Router URL 参数传递省份**：Claude 建议使用 `?province=Sichuan` 传递省份选择，团队评估后采纳——保证了可分享性（复制 URL 即可重现相同分析状态）。

3. **tailwindcss-animate + shadcn/ui 组件库**：Claude 建议使用 shadcn/ui 的 Tooltip 和 Badge 组件，我们采纳但做了定制——所有组件经过 Tailwind 二次样式覆盖以匹配水墨主题。

4. **Python 脚本的城市坐标硬编码**：Claude 最初建议使用外部 API 查询城市 GPS 坐标，团队改为在 Python 脚本中硬编码 150 个 CHARLS PSU 城市坐标（`CITY_COORDS` dict），因为离线使用更稳定且坐标经人工校对。

5. **ECharts 主题注册（ink-wash）而非 CSS 变量**：Claude 建议使用 CSS 变量统一管理颜色，但 ECharts 的 option 构建需要直接引用颜色值，因此改为在 `inkWash.ts` 中同时导出 JS 常量和注册 ECharts 主题。

## 4.3 反思

**AI 辅助的收益**：
- 显著加速了开发进程——ECharts 的复杂 option 构建（平行坐标、地图、力导向图）在 Claude 辅助下从数天缩短至数小时
- TypeScript 类型定义的完整性和一致性在 AI 辅助下得到保证
- AI 生成的 CHARLS 文献 RAG 知识库内容经过人工逐条核实后，为系统赋予了"领域知识注入"的独特能力

**AI 辅助的局限性**：
- AI 对 ECharts 特定 API 细节（如 `parallelAxis.areaSelectStyle`、自定义 `geo` 组件叠加）的理解有时不准确，需要查阅官方文档校正
- AI 生成的初版视觉设计缺乏对中国传统美学的理解，水墨主题的色彩选择和字体搭配完全由团队自主完成
- AI 在代码重构时偶尔会丢失关键的交互逻辑（如平行坐标多轴框选取交集的实现），需要人工逐条核对
- 预生成分析文本虽然经过文献交叉验证，但仍可能遗漏最新的局部研究成果——这是 RAG 方法的固有局限

**对未来 AI 辅助可视分析系统开发的建议**：
- AI 适合承担"翻译"角色（将设计意图翻译为框架 API 调用），但**分析任务的语义定义、视图与任务的匹配、多视图协调策略**仍应由领域专家做出
- 系统文档中的 Case Study 应由团队在对系统充分使用后自主撰写——AI 辅助润色可行，但核心洞察必须来自真实的系统操作体验
