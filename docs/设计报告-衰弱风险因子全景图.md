> **选题方向**: 方向 A — 多维度驱动因素分析  
> **数据**: CHARLS 2011-2020 中国健康与养老追踪调查  
> **团队**: 待定（2-3人）

---

## 一、项目背景

### 1.1 什么是"衰弱"？

**衰弱（Frailty）** 不是一种病，而是一种**身体储备全面下降的状态**。一个衰弱的老人可能看起来没有大病，但随便一次感冒、一次摔倒，就可能引发连锁崩溃。

CHARLS 用 **衰弱指数（Frailty Index, FI）** 来量化它：从 28 个维度（慢性病、日常活动能力、体能、感官、认知情绪等）计算缺陷比例。FI ≥ 0.25 即为"衰弱"。

### 1.2 这个问题为什么重要？

- 中国 60 岁以上人口已超 **2.8 亿**（2024 年数据），老龄化速度全球最快
- 学姐论文发现：在中国，**社会经济地位对衰弱的直接影响比英美更大**——医保和抑郁的中介效应相对弱，意味着"穷"本身在直接推高老年人的衰弱风险
- 另一篇论文揭示：**童年逆境（ACE）→ 社会断裂 → 抑郁 → 衰弱**是一条跨生命周期的因果链

### 1.3 为什么用可视化而不是纯统计？

统计模型（Cox 回归、中介分析等）可以给出 p 值和 HR，但无法回答这些问题：

- 东中西部老年人的衰弱风险**空间格局**长什么样？
- 不同风险因子的**相对重要性**如何一目了然？
- 个体如何在 4 波调查中**流转**于健壮→衰弱前期→衰弱之间？
- 抑郁、睡眠、社会参与、ACE——它们之间**如何相互作用**形成风险网络？

这些问题天然适合交互式可视化来回答。

## 三、数据说明

### 3.1 数据来源

**CHARLS**（中国健康与养老追踪调查），由北京大学国家发展研究院主导，是中国最权威的老年追踪调查。我们使用 2011-2018 四波数据（部分数据延伸至 2020）。

### 3.2 数据规模

| 指标 | 数值 |
|------|------|
| 总个体数 | ~43,000 |
| 追踪波次 | 4 波（2011/2013/2015/2018）|
| 每人指标数 | 28 项衰弱缺陷 + 5 类风险因子 + 9 项认知测试 + 10 项抑郁 |
| 地理粒度 | 31 个省/直辖市，3 大区域（东/中/西）|

### 3.3 核心变量

```
衰弱结局: FI（衰弱指数，0~1）、frailty_cat（健壮/衰弱前期/衰弱）

风险因子:
  ├── 社会经济: 教育年限、家庭资产、医保覆盖
  ├── 心理健康: CES-D 抑郁量表（10项，0~30分）
  ├── 睡眠: 夜间睡眠时长
  ├── 社会参与: 社交活动频率、照护支持
  └── 童年逆境(ACE): 饥荒/父母亡故/忽视/霸凌等 PCA 综合得分

地理: 社区ID → 省份 → 东/中/西区域
```

> 详细字段字典见 `data/processed/DATA_README.md`

### 4.2 页面一：总览页（Snapshot）

**目标**: 让用户 30 秒内建立对"中国老年衰弱"的全局认知。

|------|---------|---------|------|
| 顶部 KPI 卡片 | 数字 | 本波样本量、衰弱率、平均 FI、女性/农村比例 | Wave 切换自动更新 |
| 趋势堆叠面积图 | 面积图 | 健壮/衰弱前期/衰弱人数逐年变化 | Hover 显示详细数字 |
| 中国分级统计地图 | Choropleth | 31 省衰弱率，东中西色阶统一 | Hover → 省份详情；Click → 联动下方所有视图 |
| 人体隐喻图 | 人体分区 | 7 个解剖域的缺陷率（脑/心/肺/代谢/关节/ADL/感官）| Hover → 领域描述 + 平均 FI |

| 环形图 | Donut | 社交/睡眠/运动/照护 四维健康行为 | — |

| 经典症状网格 | 点阵/条形 | 疲劳/跌倒/消耗/ADL 四症状流行率 | — |

**关键交互**:
- Wave 选择器切换波次 → **所有视图同步更新**
- 点击地图省份 → 人体隐喻、症状、网络**联动筛选**该省数据

### 4.3 页面二：风险因子页（Drivers）

**目标**: 回答"哪些因素驱动衰弱？它们之间什么关系？"

| 视图 | 图表类型 | 展示内容 | 交互 |
|------|---------|---------|------|
| 因子相关性点阵 | Dot Matrix | 教育/资产/睡眠/抑郁/ACE/社会参与 vs FI 的 Spearman ρ | 按 |ρ| 排序；颜色深浅表强度 |
| Driver 热力图 | Heatmap | ACE/睡眠/社会/抑郁/FI 五者 Spearman 相关矩阵 | — |
| Driver 桑基图 | Sankey | ACE(高/中/低) → 睡眠 → 抑郁 → 衰弱结局 的个体流向 | Hover 节点看人数 |
| Driver 和弦图 | Chord | 高ACE/短睡眠/低社交/高抑郁/衰弱前期/衰弱 六者共现 | Hover 弧段看单项人数 |
| 散点图 + 小提琴图 | Scatter + Violin | 每个 Driver vs FI 的散点（≤2000采样点），按衰弱分级着色 | **框选联动** → 平行坐标高亮 |
| 平行坐标 | Parallel Coords | 5 个 Driver + FI 的多维剖面，按衰弱分级着色 | **Brushing** 联动散点图 |
| Driver 盒须图 | Box-Violin | 按区域分面的 Driver × frailty_cat 分布 | — |

**核心交互链**（这是拿分重点！）:
```
散点图上框选一群高抑郁+高FI的点
        ↓
平行坐标自动高亮对应个体
        ↓
Driver桑基图更新为仅这组人的流向
        ↓
和弦图同步显示这组人的因子共现模式
```

### 4.4 页面三：轨迹追踪页（Trajectories）

**目标**: 追踪同一批人在 8 年间（4 波）的衰弱状态变化。

| 视图 | 图表类型 | 展示内容 | 交互 |
|------|---------|---------|------|
| 4 层桑基图 | Sankey | **风险因子 → 基线状态 → 中期演变 → 终点转归**，四层嵌套 | Hover 节点/边看概率和人数 |
| 队列筛选侧栏 | Checkbox + Select | 按慢病（高血压/糖尿病/心脏病/中风/关节炎/肺病）筛选子队列 | 勾选 → 桑基图实时重建 |
| 时间跨度滑块 | Range Slider | 选择起止波次（如只看 2013→2018） | 拖动 → 桑基图中期波自动调整 |
| 趋势面积图 | Area | 被筛选队列的 FI 趋势 | 随筛选条件更新 |
| 雷达图 | Radar | 风险因子的多维对比（按结局分组） | — |
| 异常流转标注 | Badge/列表 | 自动标记 jump（加速恶化）和 recovery（逆转）路径 | Click → 桑基图高亮该路径 |

**分析流示例**:
```
1. 用户勾选"高血压 + 糖尿病" → 桑基图重建，只显示这组慢病老人的流转
2. 用户拖动时间跨度到 2013→2018 → 中间波自动变为 2015
3. 用户看到一条粗线从"衰弱前期"流向"衰弱"(prob=0.28)
4. 系统自动标注为 anomaly=jump，右侧显示解释文本
```

### 4.5 全局联动机制

| 联动方式 | 具体实现 |
|----------|---------|
| **Wave 统一选择** | 顶部 WaveSelector，切换后所有视图加载对应年份数据 |
| **Brushing & Linking** | 散点图框选 → 平行坐标高亮 → Driver 桑基更新 |
| **Details-on-Demand** | Hover 任何图表元素 → Tooltip 显示详细数值和解释 |
| **省份 → 全局** | 点击地图省份 → 联动总览页所有视图筛选该省 |
| **队列 → 轨迹** | 在轨迹页筛选子队列 → 桑基/趋势/雷达图同步更新 |

### Case Study 1: 抑郁——衰弱的"最强推手"

**分析问题**: 在所有风险因子中，哪个与衰弱关系最紧密？这种关系在时间和空间上是如何变化的？

#### Step 1: 看全局——因子相关性点阵

打开总览页 → 切换到风险因子视图 → 观察**因子相关性点阵**：

```
因子              与 FI 的 |ρ|（2018）
──────────────────────────────────
抑郁(CES-D)        0.432  ████████████████████
睡眠时长           0.220  ██████████
教育年限           0.149  ███████
社会参与           0.145  ███████
ACE 得分           0.064  ███
资产               0.155  ███████
```

**发现**: 抑郁的相关系数 **0.43**，是第二名（睡眠 0.22）的 **近两倍**，是 ACE（0.06）的 **七倍**。这个排序在 2011/2013/2015/2018 四个波次**完全一致**。

这不是偶然——抑郁是衰弱最稳定的预测因子。

#### Step 2: 看时间——趋势图 + KPI 卡片

切换到趋势堆叠面积图：

```
年份    衰弱率    平均 CES-D（来自认知抑郁数据）
2011    14.5%    8.4
2013    16.1%    7.8
2015    17.8%    7.8
2018    21.0%    8.4
```

**发现**: 衰弱率从 14.5% 升到 21.0%，四年间**绝对增长 6.5 个百分点**。但同期平均 CES-D 基本稳定在 7.8~8.4。这说明：衰弱率在上升，但**不是因为人口整体更抑郁了**，而是因为**同样抑郁水平的人，随着年龄增长更容易衰弱**。

#### Step 3: 看空间——地图 + Small Multiples

点击 2018 年地图，西部的省份（贵州 26.2%、广西 25.6%）比东部（海南 11.9%、北京约 14%）衰弱率高出一倍。切换到 Driver 盒须图 → 按区域分面：

```
区域      中位 FI    衰弱率
West      0.13      0.243   ← 最高
East      0.09      0.187
Central   0.08      0.177   ← 最低
```

**发现**: 西部不仅衰弱率高，而且 FI 分布更分散（Q3 到 max 的跨度更大），说明**西部内部的健康不平等也更严重**。

#### Step 4: 看关联——和弦图

打开 Driver 和弦图 → 看"高抑郁"弧段：

```
高抑郁 (CES-D≥上三分位): n=1,367
  ├── 同时"衰弱前期": 557 人 (40.7%)
  └── 同时"衰弱":     448 人 (32.8%)
  
  合计: 73.5% 的高抑郁者已经处于衰弱前期或衰弱！
```

对比之下，低抑郁组中仅约 30% 处于衰弱前期或衰弱。

#### 🔍 洞察总结

> **抑郁是衰弱的"最强推手"**——无论在哪个波次、哪个区域，抑郁与 FI 的 Spearman |ρ| 始终在 0.42~0.49，远超其他因子。而且 73.5% 的高抑郁老人已经处于衰弱前期或衰弱状态。但这不是宿命——约 20% 的衰弱前期老人在下一波**逆转为健壮**，意味着干预窗口确实存在。
>
> 政策含义：在老年健康管理中，**抑郁筛查应该和血压测量一样常规**。

### Case Study 2: 童年逆境的"长阴影"——ACE 如何跨越半个世纪影响晚年健康

**分析问题**: 童年经历（饥荒、家庭破裂、忽视、霸凌）会不会影响一个人 50 年后的衰弱风险？如果会，是通过什么路径？

#### Step 1: 看全局——Driver 桑基图

打开轨迹追踪页 → 切换到 4 层桑基图 → 选择"全队列"模式：

```
风险因子层 → 基线状态层 → 中期演变层 → 终点转归层
```

将风险因子按 ACE 分组观察流向宽度：

```
高 ACE 组 (n=1,143, 2011 baseline):
  ├── 基线健壮    → 中期稳定 → 终点仍健壮   (少数)
  ├── 基线健壮    → 中期恶化 → 终点衰弱前期  (较多)
  ├── 基线衰弱前期 → 中期恶化 → 终点衰弱     (典型路径)
  └── 基线衰弱    → 中期持续 → 终点衰弱     (最差路径)

低 ACE 组 (n=1,397):
  ├── 基线健壮 → 中期稳定 → 终点健壮  ← 这条路明显更宽
  └── ...
```

**肉眼可见**: 高 ACE 组流向"衰弱"的线条**明显比低 ACE 组粗**。

#### Step 2: 看共现——和弦图

切换到 Driver 和弦图（2011 年）：

```
高 ACE (n=1,388):
  ├── 同时"衰弱前期": 459 人 (33.1%)
  └── 同时"衰弱":     256 人 (18.4%)
  ─────────────────────────────
  合计: 51.5% 的高 ACE 者已经处于衰弱前期或衰弱
```

**发现**: 超过一半的高 ACE 老人已经出现衰弱迹象。这些人的童年逆境发生在 **40-60 年前**（1950s-1970s），但其效应仍然清晰可见。

#### Step 3: 看路径——Driver 桑基图的 ACE→抑郁→衰弱链路

在 Driver 桑基图（5 层：ACE → 睡眠 → 抑郁 → 社会参与 → FI）中追踪：

```
高 ACE → 短睡眠(中/低) → 高抑郁 → 低社会参与 → 衰弱
  ↑                                              ↑
  童年饥荒、父母离异、被忽视……                    晚年失能、依赖照护
```

中间的**抑郁**和**社会参与**是可以干预的环节。这为政策提供了明确的靶点。

#### Step 4: 看逆转——异常流转标注

在异常流转面板中，过滤 `kind=recovery`：

```
Recovery flow: 24.9% of pre-frail adults in 2011 reverted to robust by 2013.
Recovery flow: 20.5% of pre-frail adults in 2013 reverted to robust by 2015.
Recovery flow: 18.8% of pre-frail adults in 2015 reverted to robust by 2018.
```

**发现**: 约 **1/5 到 1/4** 的衰弱前期老人在下一波恢复为健壮！这说明**衰弱前期是一个可逆的窗口期**——如果在此时干预（改善睡眠、治疗抑郁、增加社会活动），有可能阻止滑向衰弱。

但恢复率从 2011 的 24.9% 降到 2018 的 18.8%，可能反映队列老龄化导致逆转变得越来越困难。

#### 🔍 洞察总结

> **童年逆境投下的阴影长达半个世纪**——高 ACE 老人中，超过一半（51.5%）已经处于衰弱前期或衰弱。这条路径的中介是**睡眠→抑郁→社会断裂**。但好消息是：衰弱前期有约 20% 的逆转率。如果能在抑郁和社交环节提供干预（社区老年活动中心、心理咨询可及性），就有机会切断 ACE→衰弱的链条。
>
> 政策含义：**针对高 ACE 老年人群的早期抑郁筛查和社交促进**可能是最具成本效益的衰弱预防策略。
