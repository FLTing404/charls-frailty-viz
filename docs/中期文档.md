## 1. 项目背景

### 1.1 问题定义
随着中国人口老龄化加剧，60岁以上人口已突破3亿。在健康管理中，**衰弱** 是比生理年龄更关键的预测指标，它反映了个体生理储备的下降。然而，由于衰弱涉及生理、心理、社会等多维因素，且在地理分布上具有显著异质性，传统的统计报表难以直观、动态地揭示其演变模式与驱动机制。

### 1.2 可视分析的必要性
- **多尺度空间异质性解构：** 中国老龄化进程呈现出显著的地理梯度，城乡二元结构及区域经济差异导致衰弱患病率分布极不均衡。传统统计报表受限于数据聚合粒度，往往会掩盖局部异常特征。通过交互式地理填充地图，系统支持从全国尺度平滑下钻至省级及特定政策区域，通过空间维度的动态缩放，深入挖掘地理分布与社会经济指标、医疗资源投放之间的深层耦合关系。
- **高维关联下的协同效应挖掘：** 衰弱状态并非多项生理缺陷的简单叠加，而是慢病、抑郁心理、早期逆境及社会孤立共同驱动的复杂系统。在面对这种高维、非线性的关联关系时，传统统计模型难以直观呈现多因素间的协同效应。系统建立多视图联动机制，支持在平行坐标轴上动态探索子群特征，通过识别特定风险因子的聚集模式，揭示统计平均值下隐藏的隐性高危剖面，将复杂的数据关系转化为工程直观的分析洞察。
- **从现象到机理的叙事化逻辑：** 系统遵循“总览、过滤、按需细节”的可视化设计准则，构建了从宏观规律到微观归因的逻辑链路。宏观概览页采用分区布局建立地理空间感知，结合人体认知隐喻增强对数据语义的理解；随后引导用户进入探究页执行归因分析。这种从空间现象到多维动因的分析流转，不仅极大提升了高复杂度数据的可解释性，更辅助决策者在多源数据流中构建逻辑闭环，为制定精准干预策略提供科学工程依据。

## 2. 分析任务定义

本系统旨在辅助公共卫生研究者执行以下任务：

| 任务 ID | 分析任务名称 | 描述 | 对应视图 |
| :--- | :--- | :--- | :--- |
| **T1** | **空间格局对比** | 探索全国及各省衰弱指数的地理分布及年度变化。 | 省级填充地图、区域小倍数图 |
| **T2** | **共病模型分析** | 理解衰弱人群常伴随的慢病组合及生理功能缺陷特征。 | 共病力导向网络、人体症状图 |
| **T3** | **多维归因探索** | 分析童年逆境、睡眠时长、抑郁及社会参与对衰弱的相关性。 | 相关性热力图、平行坐标图 |
| **T4** | **子群规律发现** | 刷选特定生活方式（如短睡眠、低社会联系）的人群，观察其衰弱轨迹。 | 轴刷选、多图表联动状态切换 |
| **T5** | **跨波次追踪** | 观察个体或群体在 2011-2018 间的衰弱状态转移模式。 | 桑基图、和弦图、散点演变图 |

## 3. 数据说明

### 3.1 数据来源
1. **CHARLS 调查数据：** 来源于北京大学发布的《中国健康与养老追踪调查》（2011, 2013, 2015, 2018 四波数据），涵盖生理、心理、社会参与等大量原始数据。
2. **衰弱指数：** 由团队基于 28 项缺陷累积模型构建，计算个体在各波次的分值及其三分类状态。

### 3.2 数据属性与规模
- **样本规模：** 各波总计约 10 万+ 记录，清洗后的追踪队列包含两万余名稳定观察对象。
- **关键属性：** 
    - **地理：** 省份、城乡、东中西区域。
    - **结局：** 衰弱指数（连续型 0.0-1.0）、衰弱状态（健壮/前期/衰弱）。
    - **动因：** 童年得分、抑郁得分、睡眠时长、社会参与频率。

### 3.3 数据处理流程
使用 Python 实现自动化预处理流水线，核心产物包括：
- 省级聚合 JSON（均值、患病率）。
- 驱动因素个体记录（用于平行坐标与散点图）。
- 状态转移矩阵（用于和弦图与桑基图）。

## 4. 设计方案

### 4.1 总体架构
系统采用双页钻取结构，风格定义为**中国水墨叙事风格**：
- **第一页：宏观概览**。侧重空间分布与生理共病截面。
- **第二页：微观探究**。侧重个体因素归因与多维刷选探索。

### 4.2 视觉设计规范与审美构建
- **核心理念：数字水墨**。系统不追求传统仪表盘的锋利边界，而是利用透明叠色和线条张力，模拟水墨的扩散与意境。
- **色彩设计：**
    - **背景色：** `#F7F3EB` (古籍宣纸色)，营造历史厚重感。
    - **辅助色：** `#5C7A6B` (竹青 - 健壮)、`#C4A35A` (秋葵 - 前期)、`#B83B3B` (朱砂 - 衰弱)。
    - **笔触：** 图表轴线采用 `#D1CFCD` (云雾灰)，弱化背景干扰，突出数据线条。
- **全局布局优化方案：** 采用**非对称式比例布局**。第一页将重构 3-6-3 的比例配置，加大地图视觉中心；第二页则强调多维关联分析的横向延展性。

### 4.3 第一页：宏观格局概览设计
- **空间与生理特征协同调度**：中央地图不仅是地理展示，更是全局过滤引擎。通过点击省份触发响应式状态机更新，实现侧边栏样本统计数据与人体症状视图的毫秒级同步刷新。
- **隐喻式生理特征建模视图**：基于 SVG 的抽象人体模型，将衰弱评价体系中的 28 项指标科学归类为视觉、听觉、动作、认知等生理功能域。利用水墨浓淡的视觉编码表现受损程度，建立起数据与医学现实之间的认知桥梁。

### 4.4 第二页：微观驱动探究设计
- **平行坐标系的沉浸式高维过滤**：
    - **视觉分层渲染策略**：采用非对称透明度映射，将背景全量人群设为低对比度浅墨色，而将刷选后的目标子群设为高饱和度的朱砂红，通过视觉显著性差异有效降低视觉过载。
    - **交互式多轴联合刷选**：支持在多个维度坐标轴上执行联合布尔刷选，动态观察高危因子在多维空间中的漂移规律。
- **归因逻辑视图切换**：集成桑基图、和弦图、散点演变图等进阶图表，支持从概率转移、权重流动及演化趋势等多个数学视角审视驱动因素的贡献度。

### 4.5 状态管理与数据联动
- **全局响应式 Store**：构建中心化状态机，统一管理波次、省份和衰弱分类等全局上下文。
- **页面级动态计算流**：维护平行坐标系的实时刷选 ID 列表，并将其作为流水线输入，驱动底盘分组图表（如箱线图等）生成实时对比统计量。
